## Текущий рабочий процесс

Вопрос с известным товаром и каноном → автоматический ответ Luna через OpenRouter → человек выбирает Да / Нет / Переделать. Да публикует, Нет отклоняет и переходит дальше, Переделать запрашивает замечание отдельной строкой. Вызовы модели не повторяются автоматически. Сессия ограничена числом вопросов; исправления запускаются отдельно самим оператором.

## Осталось доработать и принять

1. Последнее пожелание владельца пока не внесено: в одном поле ввода точное «Да» должно публиковать, точное «Нет» отклонять, любой иной непустой текст сразу становиться замечанием для переподготовки. Сейчас требуется отдельный выбор «Переделать» и затем ввод замечания. По просьбе владельца код оставлен в текущем виде.
2. Если канон не позволяет ответить, модель передаёт вопрос оператору и сессия останавливается. Нужно согласовать дальнейшую маршрутизацию таких случаев без потери очереди.
3. В новой установке рабочий кабинет следует явно указать в команде review-session. Автоматическое сохранение выбора установщиком для обычного mra.command ещё требует завершения.
4. Право чтения полного каталога у текущего ключа Ozon Deppa MSK отсутствует. Обработка подтверждённого SKU использует свежий вопрос из API и карту конкретного кабинета; это не подтверждает полноту матрицы. Для полноценного обновления каталога нужен соответствующий доступ.
5. Другие кабинеты и каналы отзывов не прошли тот же натурный цикл. Настройки, разрешения и подписки проверяются отдельно. Успешные два ответа не заменяют эту проверку.
6. После доработок повторить совместную приёмку и оформить коммит в согласованном GitHub-репозитории. Фоновый режим без человека — отдельный следующий этап.
