# Начать работу с MRA

Дважды нажмите **start.command**. Стартер проведёт по шагам:

1. Выбрать кабинет WB, Ozon или Яндекс Маркета.
2. Выбрать провайдера и модель: OpenRouter/Luna, OpenRouter/Sol либо прямой OpenAI/Sol.
3. Заполнить открытые TXT-файлы ключа выбранного кабинета и провайдера. Для Ozon отдельно заполнить Client-Id. Все пустые файлы для шести кабинетов и двух провайдеров находятся в **private/credentials**.
4. Нажать Enter после сохранения. Стартер проверит заполнение, подготовит SQLite, проверит знания и доступ к вопросам.
5. Ввести **СТАРТ**, чтобы начать платную рабочую сессию с человеком в петле.

Для начала достаточно одного кабинета и одного провайдера. Другие файлы можно заполнить позже. Ключи — обычный текст, одно значение в каждом файле, без кавычек и JSON. Стартер не выводит содержимое ключей. Папка private/ игнорируется Git и исключается из ZIP исходников; после распаковки start.command создаёт пустые файлы автоматически.

Текущий сценарий сессии: наушники, только товары с материалом в каноне. Оператор видит сразу вопрос и готовый ответ. **Да** публикует, **Нет** отклоняет и переходит дальше. **Переделать** запрашивает замечание отдельной строкой и создаёт новый вариант для проверки. Запросы модели ограничены 2000 выходных токенов, сессия — 20 вопросами; повторов по ошибке нет. Для выхода — Ctrl+C.

При новом запуске стартер использует сохранённый кабинет и провайдера. Чтобы поменять их, выполните `./start.command --setup`. Локальная подготовка без API и без рабочей сессии: `./start.command --prepare-only`.

В терминале: `./start.command`. Требуется Python 3.9+; если его нет, сначала установите Python. Зависимости PyPI не нужны.

Подробности: [DEPLOYMENT](DEPLOYMENT.md). Что реализовано и осталось: [СОСТОЯНИЕ ПЕРЕДАЧИ](СОСТОЯНИЕ%20ПЕРЕДАЧИ.md). План самостоятельной работы: [AUTONOMOUS_MODE](AUTONOMOUS_MODE.md). Меню обслуживания: `./mra-cli terminal`.
